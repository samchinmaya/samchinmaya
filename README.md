## 🏗️ Key Projects

### ⚡ [n8n Clone](https://github.com/samchinmaya/n8n) (Workflow Automation) · *in progress*
A workflow automation tool inspired by n8n, built from scratch in TypeScript.
*   **Workflow Engine:** Runs connected nodes in order (trigger → HTTP request → set), passing each node's output to the next.
*   **REST API:** Built with **Elysia**, with request validation using **arktype**.
*   **Database:** **PostgreSQL** (Neon) with **Drizzle ORM** schemas and migrations for users, workflows, credentials and executions.
*   **Coming next:** Job queue with **Redis + BullMQ**, webhook and cron triggers, auth with **better-auth**, and a drag-and-drop editor with **React Flow**.
